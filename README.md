# Real World Agents

I gave Grok Bot an org chart instead of a to-do list.

Eight seats. One floor. You assign outcomes. They do the work.

This repo is the setup from the original post:
https://x.com/ridark_eth/status/2090138832511324179

## What this is

Not a smarter chat window.

A roster you can hand work to:

- Atlas — chief of staff. The only bot you talk to.
- Scout — research. Verified prospects only.
- Quill — content. Drafts in your voice. Never publishes.
- Pitch — outbound. Short, specific, queued for approval.
- Vault — inbox and ops. Zero inbox by morning.
- Ledger — one number a night.

The original post named eight bots. Start with these six.
Add the seventh and eighth only after the floor is stable.

## Two rules

1. Every charter ends with a hard "never do this without asking" line.
   Autonomy without a fence is chaos on a schedule.
2. Show once, don't describe.
   Run the workflow on your screen one time. That demo teaches more than a page of instructions.

## Wiring

One group chat per outcome, not per person.
Atlas sits in every chat.
Bots hand off inside the chat.
You read the handoff. You do not manage the work.

## Week-one target

Use this as the first scoreboard, not as a promise:

- 214 verified prospects
- 89 personalized outreaches queued and approved
- inbox at zero every morning
- 11 content pieces ready

Your numbers will be different. The shape should not be.

## Quick start

1. Read `SETUP.md`
2. Create Atlas first. Paste `charters/atlas.md`
3. Create the specialists. Paste their charters.
4. Put Atlas in every outcome chat.
5. Teach by screen recording once.
6. Give Atlas an outcome, never a task list.

## Files

- `RULES.md` — fences that keep the floor from going feral
- `SETUP.md` — install order
- `charters/` — job descriptions
- `templates/` — the exact output formats
